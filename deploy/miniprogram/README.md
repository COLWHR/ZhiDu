# 小程序部署说明

这个目录只保存微信小程序的部署材料，不改动 web 端后端和前端代码。

## 部署目标

- 服务器：`150.158.166.38`
- 服务器用户名：`ubuntu`
- 小程序部署目录：`/opt/zido/miniprogram`

## 说明

微信小程序本身不是像 web 页面那样通过 Nginx 直接对外访问的静态站点。
这里的“部署”指的是把小程序源码同步到服务器的独立目录，和 web 项目共用同一套后端接口。

## 同一套后端

小程序代码默认指向：

- `https://zhuanerzhuxue.cn/api/v1`

web 端继续使用原来的后端地址，不需要改后端逻辑。

## 同步方式

推荐在能连到服务器的机器上执行 `sync.ps1`。

如果你想手工执行，也可以把 `miniprogram/` 整个目录传到服务器的 `/opt/zido/miniprogram`。
