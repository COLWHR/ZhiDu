# 腾讯云部署检查清单

按下面顺序逐项确认，尽量避免踩坑。

## 1. 代码与构建

- [ ] 前端可以正常执行 `npm run build`
- [ ] 后端可以正常执行 `python -m py_compile app/main.py app/core/config.py`
- [ ] `docker-compose.yml` 已按当前仓库内容配置
- [ ] 项目根目录包含 `.dockerignore`

## 2. 环境变量

- [ ] `ENVIRONMENT=production`
- [ ] `SECRET_KEY` 已设置为足够长的随机字符串
- [ ] `API_KEY` 已设置为可用的模型服务密钥
- [ ] `MODEL_NAME` 与实际可用模型一致
- [ ] `BASE_URL` 与实际接口地址一致
- [ ] `DATABASE_URL` 与部署方式一致
- [ ] `REDIS_URL` 与部署方式一致

## 3. 安全项

- [ ] `.env` 没有被提交到仓库
- [ ] 真实密钥没有写进镜像
- [ ] 生产环境没有继续使用默认 `SECRET_KEY`
- [ ] 云服务器只开放必要端口
- [ ] 如需公网访问，建议使用 Nginx + HTTPS

## 4. 云服务器状态

- [ ] 系统已更新
- [ ] Docker 已安装并能正常启动
- [ ] `docker compose` 可用
- [ ] 磁盘空间足够
- [ ] CPU 和内存有余量

## 5. 部署后验证

- [ ] `docker compose up -d --build` 无报错
- [ ] 容器状态为 `Up`
- [ ] 首页可以正常打开
- [ ] 登录页可以正常访问
- [ ] 时空之门可以正常发消息
- [ ] 图片上传可以正常使用
- [ ] 日志里没有持续出现 401、500 或数据库锁错误

## 6. 上线前最后确认

- [ ] 已备份数据库
- [ ] 知道如何回滚到上一版
- [ ] 对外展示内容中没有敏感信息
- [ ] 模型服务额度足够支撑验证和上线初期流量
